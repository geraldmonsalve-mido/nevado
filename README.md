# NEVADO
Infraestructura digital para reconstruir el capital humano venezolano.

v3.0 — Vite + Vanilla JS + Three.js  
37 páginas funcionales · Sistema Croquetas · Chat IA integrado

## Stack
- Vite (build tool)
- Vanilla JS + Three.js (home 3D)
- API Anthropic (claude-sonnet-4-5)

## Variables de entorno
Copia `.env.example` como `.env.local` y agrega tu key.

## Dev
npm install && npm run dev
